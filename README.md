# XWVM 臺灣正體中文在地化專案 (Traditional Chinese Localization for XWVM)

本專案致力於為 1990 年代 LucasArts 經典太空飛行模擬遊戲《星際大戰：X翼戰機》（*Star Wars: X-Wing*）的現代開源重構引擎 —— **[XWVM](https://github.com/JeremyWildsmith/XWVM)**，提供高品質且完整的臺灣正體中文（`zh-TW`）在地化文本。

---

## ⚠️ 重要生效聲明 (Important Notice)

> [!IMPORTANT]
> **本專案目前已完成全文本 100% 繁體中文在地化翻譯。**
> 
> 然而，由於目前 **XWVM 上游官方引擎** 在文字排版與字型渲染管線上主要設計給拉丁字母語系（Latin-based scripts），**尚未正式實裝對 CJK（中日韓等「非拉丁語系」Non-Latin Scripts）的 TrueType / SDF 動態字型渲染與 Unicode 支援**。
> 
> 因此，本翻譯文本**必須等待 XWVM 上游引擎官方完成對「非拉丁語系」的文字支援更新後，才能在遊戲本體中正常顯示與完全生效**。
> 
> 歡迎關注 [XWVM 官方倉庫](https://github.com/JeremyWildsmith/XWVM) 的字型與語系渲染開發進度。

## 🌟 專案特色與在地化方針

1. **原汁原味復古軍事風**：
   - 秉持 1990 年代硬派太空飛行模擬風格，文字短潔有力、專業俐落，避免現代網路流行語。
   - 戰術簡報、駕駛艙抬頭顯示器（HUD）、機載損害管制與僚機無線電通訊皆忠實呈現身歷其境的座艙氛圍。
2. **臺灣星戰正史與社群權威譯名**：
   - 嚴格考據並統一臺灣官方院線、小說正史及經典星戰社群（如 StarWarsAlly、星戰同好會）公認之譯名（如：*滅星艦*、*鈦戰機*、*散熱排氣孔*、*阻絕者巡洋艦*、*蒙卡拉馬里*、*質子魚雷*、*達斯維達*、*莉亞公主*、*霍斯星* 等）。
   - 提供專屬權威辭典 [`GLOSSARY.csv`](GLOSSARY.csv) 與 [`GLOSSARY.md`](GLOSSARY.md)。
3. **精確控制避免介面溢出**：
   - 針對 DOS / 90 年代原始解析度與有限 UI 視窗進行字數精修，防止字串過長發生「爆框」或排版截斷。
4. **技術結構完整性**：
   - 嚴格保留所有 XLIFF 2.0 格式規範、`<source>` 原始英文字串未受更動。
   - 完整保留所有遊戲邏輯代碼、變數標籤（如 `{0}`、`{player}`、`$ / $$` 停頓符、`[[...]]` 簡報高亮標記及 XML 實體跳脫）。

## 📁 專案檔案結構

```text
.
├── zh-TW/                  # 臺灣正體中文在地化目錄
│   ├── CSV/                # 機體載具元數據 (Species) 設定檔 (X-Wing & TIE Fighter)
│   └── XLIFF/              # XLIFF 2.0 格式語系翻譯檔目錄 (共 36 個檔案)
│       ├── XWVM.Common.*   # 戰鬥術語、機庫、勳章、軍階、HUD 系統介面
│       ├── XWVM.UI.*       # 遊戲庫、ESC 設定選單
│       ├── XWVM.tf.*       # TIE Fighter 關聯過場與小提示
│       └── XWVM.xwing.*    # X-Wing 戰役 (Tour 1~5)、歷史任務、額外任務、影片字幕
├── GLOSSARY.csv            # 翻譯名詞權威檔 (CSV 格式，方便試算表與社群協同檢視)
├── GLOSSARY.md             # 翻譯名詞權威檔 (Markdown 格式排版)
├── agent.md                # 翻譯技術規範與 Prompt 準則
├── references/             # 歷史星戰譯名參考與網路存檔備份
└── README.md               # 專案說明文件
```
